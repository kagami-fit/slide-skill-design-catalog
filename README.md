# スライドスキル デザインカタログ

スライド生成スキルごとのデザイン傾向を、実生成画像・参照トーン・スタイル見本で見比べられる静的HTMLサイトです。

## できること

- 23種類のスライド生成スキルを一覧表示
- 150枚分の生成スライドを比較
- スキル名、用途、色、タグで検索・絞り込み
- 参照トーンと生成結果をコンタクトシートで比較

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドは不要です。

```bash
open index.html
```

GitHub Pagesで公開する場合は、`main` ブランチのルートを公開元にしてください。
